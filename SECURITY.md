# Security Policy

## Supported versions

Security fixes are made on the latest published version. This package is experimental
while it is in `0.x`; update to the latest release before reporting an issue.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/smithclay/cloudflare-codemode-monty/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include a minimal reproduction, affected version, impact, and any suggested mitigation.
We will acknowledge reports within seven days and coordinate disclosure and a fix with
the reporter when applicable.
